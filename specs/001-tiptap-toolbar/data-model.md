# Data Model: Rich Text Toolbar and Editor

**Branch**: `001-tiptap-toolbar` | **Feature**: Rich Text Toolbar and Editor

## Entities

### 1. NoteDocument (Domain Entity)
Represents the rich text note content authored by the student.

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `string` | Yes | Unique note identifier (UUID). |
| `courseId` | `number` | Yes | Parent course identifier (links to Course). |
| `content` | `string` | Yes | Serialized HTML or JSON representation of the rich text document. |
| `createdAt` | `string` (ISO 8601) | Yes | Creation timestamp. |
| `updatedAt` | `string` (ISO 8601) | Yes | Last edit timestamp. |
| `lastProcessedAt`| `string \| null` | No | Study planner processing timestamp. |

#### Document Schema Rules
- Root node: `doc` (top-level block container).
- Block nodes: `paragraph`, `heading` (levels 1, 2, 3), `bulletList`, `orderedList`, `listItem`, `blockquote`, `horizontalRule`, `image`.
- Inline marks: `bold`, `italic`, `strike`, `code`.

---

### 2. ImageAttachment (Transfer Entity)
Represents media uploaded through the editor toolbar.

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `string` | Yes | Image asset identifier generated by the server. |
| `url` | `string` | Yes | Accessible HTTP URL for image retrieval (`/api/images/{id}`). |
| `contentType` | `string` | Yes | MIME type (e.g. `image/png`, `image/jpeg`). |
| `size` | `number` | Yes | File size in bytes. |
| `createdAt` | `string` (ISO 8601) | Yes | Upload timestamp. |

#### Validation Rules
- Supported MIME types: `image/jpeg`, `image/png`, `image/webp`, `image/gif`.
- Max upload size: 10 MB per file.
- Reject corrupt or zero-byte files prior to insertion.

---

### 3. ToolbarActionItem (Presentation View Model)
Defines each button in the rich text toolbar.

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `string` | Yes | Unique action key (e.g. `bold`, `undo`, `image`). |
| `label` | `string` | Yes | Accessible label / tooltip text. |
| `icon` | `Component` | Yes | Lucide Vue icon component. |
| `group` | `'history' \| 'block' \| 'inline' \| 'list' \| 'media'` | Yes | Layout grouping category. |
| `isActive` | `() => boolean` | No | Callback returning true if style is active at current cursor. |
| `canExecute` | `() => boolean` | No | Callback returning false if action is currently disabled. |
| `action` | `() => void` | Yes | Command execution trigger. |

---

## State Transitions (Editor History)

```text
[Initial / Empty State]
    │
    ▼ (User types or formats)
[Modified State] (undo: enabled, redo: disabled)
    │
    ▼ (User clicks Undo)
[Reverted State] (undo: conditional, redo: enabled)
    │
    ▼ (User clicks Redo)
[Restored State] (undo: enabled, redo: disabled)
```
